# Name-variant matrix

Build one table per surname and per frequent given name. Search every form.

| Axis | Examples / rules |
|---|---|
| Script | Cyrillic (ru, be), Latin (pl, lt, la), Hebrew/Yiddish for Jewish records |
| Polish orthography | cz ↔ ч, sz ↔ ш, rz ↔ ж/р, ć/ci ↔ ць/ть, ś/si ↔ сь, ł ↔ л/ў, w ↔ в, -owicz/-ewicz ↔ -ович/-евич |
| Belarusian | akanye (а for unstressed о: Кавалевіч ↔ Ковалевич), дзеканне/цеканне (дз/ц for д/т before soft vowels), ў |
| Russian bureaucratic | т ↔ ц after normalization (‑тевич ↔ ‑цевич), -ов/-ев suffixes, "по отцу" patronymics as surnames |
| Lithuanian | -avičius/-evičius, -as/-is endings, feminine -ienė/-aitė/-ytė |
| Latin (church books) | Joannes = Ян/Иван, Jacobus = Якуб/Яков, Gregorius = Hryhory/Гришка; genitive forms (Joannis) |
| Diminutives | Hryszko/Гришка/Hryń; Pawluk/Павлюк = Paweł; Iwaszko = Iwan; Jurko = Jerzy/Юрий; Choma = Фома |
| Prefixes / truncations | O-/Ho- prefixes (Hryniewicz ↔ Охриневич type shifts), dropped initial letters, first-syllable shifts |
| Transliterations | BGN/PCGN, ISO 9, Belarusian passport (Kavalevich), German (Kowalewitsch), French |
| Clerical errors | o/a, e/i swaps; ч/ц, т/ц confusion in handwriting; dropped endings |

Given-name equivalence across languages is a frequent cause of missed matches: keep a table
Polish ↔ Russian ↔ Belarusian ↔ Latin ↔ Lithuanian for each person.

Female forms: Polish -owa/-ówna, -ina; Russian -ова/-ева/-ина; Belarusian -ова/-ава/‑ыха in village usage;
widows often appear as "wdowa X" or "Xicha/Xowa" (e.g. Kurylicha = widow of Kuryło).
