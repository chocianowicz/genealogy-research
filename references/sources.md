# Sources (with reliability class)

Classes: **A** official/original holdings · **B** reputable index or thematic project · **C** community lead ·
**Q** quarantine (do not use as evidence; avoid personal-data aggregators).
Always prefer the original scan; record shelfmark + URL + access date. Re-verify URLs — sites change.

## Ukraine
| Class | Resource | Use |
|---|---|---|
| A | Central State Historical Archives of Ukraine in Kyiv (CDIAK) and Lviv (CDIAuL); oblast archives | Volhynia, Podolia, Kyiv and Galicia fonds; catalogues partly online, many requests by e-mail; archive site returned HTTP 403 to a script, check it in a browser |
| A/B | FamilySearch catalogue (filmed Ukrainian fonds) | metric books by guberniya, uezd, parish and year; mostly unindexed images; user logs in |
| C | Geni, VGD.ru forum (forum.vgd.ru) | leads and volunteer help; Russian-language; verify against scans, do not use as evidence |

Pre-1917 guberniya and uezd decide which archive holds a record; modern oblasts do not match them. Records
destroyed in WWII are uneven: check the finding aid before giving up.

## Jewish records (Pale of Settlement: LT, BY, PL, UA)
| Class | Resource | Use |
|---|---|---|
| B | JewishGen (jewishgen.org) | town and vital-records indexes, Locality Database (which records exist per town), Yizkor books, cemetery and Holocaust databases; indexes only, go back to the scan or archive for the record |
| B | Gesher Galicia | see Poland |
| A/B | State archives (LVIA, NIAB, Polish and Ukrainian archives) | Jewish metric books were kept separately, often in Russian; many survive in state archives |

Town names differ by language (Vilna = Wilno = Vilnius, Kovno = Kowno = Kaunas): search every variant
(`name-variants.md`). Jewish families took fixed surnames in the early 1800s, often German or Yiddish forms.
